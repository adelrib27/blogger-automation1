# V31 — E-mail público padrão de contato de blogs Blogger

Decisão explícita do proprietário em 22/11/2026: o endereço público de contato usado nos blogs Blogger deste projeto é blogbloggerautomation@gmail.com.

## Instruções operacionais
- Utilizar este endereço quando criar ou revisar páginas de Contato de blogs Blogger do V31, sem inventar outro destinatário.
- Incluir, conforme necessidade, link mailto e formulário FormSubmit HTML apontando a https://formsubmit.co/blogbloggerautomation@gmail.com.
- Incluir aviso de privacidade, consentimento para uso de serviço externo, proteção anti-spam e alternativa mailto. Não solicitar dados sensíveis.
- A instalação de HTML, por si só, NÃO prova que o formulário está ativo. O serviço pode exigir confirmação do e-mail na primeira submissão; checar recebimento real antes de declarar a entrega funcional.
- Antes de publicar, verificar se o XML do tema não suprime data:post.body para Contato.
- A preferência por este endereço não autoriza mudanças em credenciais de outras contas, envios de mensagens a terceiros, publicação LIVE automática ou uso de formulários sem aviso de privacidade.
